# Pain Management Support Group Website
    
    ## Deployment Instructions
    
    ### For Firebase (edmhs.us):
    1. Extract this ZIP file
    2. Install Firebase CLI: npm install -g firebase-tools
    3. Login: firebase login
    4. Initialize: firebase init hosting
    5. Deploy: firebase deploy
    
    ### For Network Solutions (edmhs.org):
    1. Extract this ZIP file
    2. Upload all files via FTP or file manager
    3. Ensure index.html is in the root directory
    
    ## DNS Configuration
    See DNS_CONFIGURATION_GUIDE.md for detailed DNS setup instructions.
    
    ## File Structure:
    - index.html (homepage)
    - pages/ (about, resources, meetings, contact)
    - css/styles.css (all styles)
    - js/script.js (navigation & form handling)
