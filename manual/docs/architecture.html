PMSG Platform: Comprehensive Guide to Pain Management Support Group Informatics

Chapter 3 Platform Architecture

3.1 Overview

The PMSG platform employs a modern, microservices-oriented architecture designed for scalability, maintainability, and extensibility.

3.2 Technology Stack

3.2.1 Frontend Stack

  • React 18.2
  • Recharts for visualizations
  • Tailwind CSS
  • JWT authentication

3.2.2 Backend Stack

  • FastAPI (Python 3.9+)
  • PostgreSQL 12+
  • Redis (caching)
  • Celery (async tasks)

3.2.3 Analytics Stack

  • R 4.0+
  • Shiny Server
  • ggplot2, plotly
  • Statistical packages (lme4, survival, etc.)

3.2.4 AI/ML Stack

  • ChromaDB (vector database)
  • Sentence Transformers
  • LangChain
  • Claude API
